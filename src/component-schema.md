# Компонентная схема сервисов

Схема иллюстрирует архитектуру системы управления БПЛА, обеспечивающей автономный полет в условиях отсутствия GPS/ГЛОНАСС. Ключевые компоненты и их взаимодействие:

Наземная станция:
- Оператор управляет дроном через наземную станцию (ноутбук), подключенную к локальной сети.
- БД (Файловая система) наземной станции хранит миссии, настройки и данные телеметрии.
- Станция взаимодействует с дроном через роутер, обеспечивая передачу команд и видеопотока.

Бортовой модуль на Raspberry Pi 5:
- Является ядром системы: обрабатывает данные с камеры IMX477 (оптический поток, нейросетевое обнаружение объектов) и дальномера TFMini (высота, препятствия).
- Через UART-соединение и протокол MAVLink отправляет команды на полетный контроллер дрона и получает телеметрию.
- БД (Файловая система) Raspberry Pi 5 хранит локальные миссии, параметры полета и результаты анализа видеопотока.
